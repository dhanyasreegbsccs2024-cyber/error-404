# ForgeSight

ForgeSight is a responsive smart-manufacturing operations console for browser camera inspection, AI quality review states, and live machine telemetry.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL in a browser. Use **Enable camera** to request `getUserMedia` access, then **Run inspection** to exercise the simulated AI inspection loop. The telemetry and alert values are representative UI data ready to be connected to an IoT gateway or model service.

## Build

```bash
npm run build
```
